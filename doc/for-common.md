## TANE Core とは

TANE Core は、桐光学園の文化祭などのイベントで使用するデジタルマップアプリ「TANE Map」のコンテンツを編集・管理するための管理ツールです。マップイベントの作成、場所の登録、スタンプラリーの設定など、TANE Map で必要となる情報を編集することができます。

### 主な機能

-   マップイベント（文化祭など）の作成・編集
-   イベント内の場所や階層の管理
-   地図上の位置情報の編集
-   スタンプラリー機能の管理
-   画像のアップロードと管理
-   お知らせの投稿・管理

TANE Core で編集した内容は、TANE Map アプリに反映され、来場者がスマートフォンなどで閲覧できるようになります。

### 技術情報

TANE Core は以下の技術を使用して開発されています：

-   React
-   Firebase（データベース）
-   Jotai（状態管理）
-   TailwindCSS（スタイリング）
-   TypeScript
-   NextUI（UI コンポーネント）
-   Vite（ビルドツール）

## URL 構成

TANE Core の主な URL は以下の通りです：

-   `https://core.toko-tane.net/` - メインページ（ログイン後のホーム画面）+ ログインページ（未ログイン時）
-   `https://core.toko-tane.net/account` - アカウント情報ページ
-   `https://core.toko-tane.net/map` - マップイベント一覧
-   `https://core.toko-tane.net/map/[イベントID]` - 特定のイベントの編集ページ
-   `https://core.toko-tane.net/map/[イベントID]/place/[場所ID]` - 特定の場所の階層管理
-   `https://core.toko-tane.net/map/[イベントID]/stampRally` - スタンプラリーの管理
-   `https://core.toko-tane.net/images` - アップロードされた画像の一覧表示
-   `https://core.toko-tane.net/upload` - 画像アップロードページ
-   `https://core.toko-tane.net/message` - お知らせ管理ページ
-   `https://core.toko-tane.net/help` - ヘルプページ
-   `https://core.toko-tane.net/markdown` - マークダウン記法ガイド
-   `https://core.toko-tane.net/user-management` - ユーザー管理ページ（管理者のみ）
-   `https://core.toko-tane.net/for-developers` - 開発者向け情報

## アカウントとログイン

TANE Core を利用するには、アカウントが必要です。ログインには、基本的に桐光学園のメールアドレス（`@toko.ed.jp`で終わるアドレス）が必要です。

### ログインの手順

1. `https://core.toko-tane.net/`にアクセスします
2. 「ログイン」ボタンをクリックします
3. Google アカウントでログインします（桐光学園のメールアドレスを使用）
4. 初回ログイン時は自動的に「閲覧者（READER）」として登録されます

### アカウント情報の確認

アカウント情報は「アカウント」ページで確認できます：

1. サイドバーから「アカウント」をクリックします
2. ユーザー名、メールアドレス、権限などの情報が表示されます
3. 「サインアウト」ボタンからログアウトできます

## ユーザー権限の説明

TANE Core では、ユーザーごとに権限が設定されています。権限によってできることが異なります。

### 権限の種類

| 権限   | 名称         | 説明                         | できること                                                               |
| ------ | ------------ | ---------------------------- | ------------------------------------------------------------------------ |
| BANNED | 禁止ユーザー | アクセスが制限されたユーザー | 閲覧不可                                                                 |
| READER | 閲覧者       | 基本的な閲覧のみ可能         | コンテンツの閲覧のみ                                                     |
| EDITOR | 編集者       | コンテンツ編集が可能         | マップイベント・場所の編集、画像のアップロード、スタンプラリーの管理など |
| ADMIN  | 管理者       | すべての機能にアクセス可能   | EDITOR の全機能 + ユーザー権限の管理                                     |

### 画像アップロード権限

画像のアップロードは以下の条件を満たすユーザーのみ可能です：

-   権限が「EDITOR」または「ADMIN」であること
-   メールアドレスが`@toko.ed.jp`で終わること

権限の変更は管理者（ADMIN）のみが行えます。権限の変更が必要な場合は、管理者に連絡してください。

## 基本的な使い方

### ホーム画面の操作

ログイン後、TANE Core のホーム画面が表示されます。ホーム画面には以下の要素があります：

1. **初めて利用する場合**のセクション：

    - 詳細な説明書への Google ドキュメントリンクがあります
    - 操作方法に迷った場合はこちらを参照してください

2. **クイックアクセスカード**：

    - マップイベント管理（最も大きいカード）
    - ユーザー管理（管理者のみ）
    - アカウント情報
    - ヘルプ
    - 画像一覧
    - 開発者向け情報
    - 画像アップロード

3. **サイドバー**：
    - ホーム
    - ユーザー管理（管理者のみ）
    - 画像一覧
    - 画像アップロード
    - マップイベント
    - リアルタイム連絡（お知らせ管理）
    - アカウント
    - 関連リンク
    - ヘルプ
    - マークダウンガイド
    - 開発者用情報

### マップイベントの管理

マップイベントとは、文化祭などのイベント単位を指します。

#### マップイベントの作成（管理者のみ）

1. サイドバーから「マップイベント」をクリックします
2. 「マップイベントの新規追加」ボタンをクリックします
3. 必要事項を入力します：
    - ID：イベントを識別する一意の ID（半角英数字のみ）
    - 名前：イベントの名前
    - 見出し：イベントの簡単な説明
    - リンク：関連するウェブサイトの URL
    - 画像 URL：イベントのメイン画像の URL
    - マップ画像 URL：イベントの地図画像の URL
    - 開始日時/終了日時：イベントの開催期間
    - 場所名/位置情報：イベントの開催場所
4. 「追加」ボタンをクリックして作成を完了します

※一度作成したイベントは削除できないので注意してください。

#### マップイベントの編集

1. サイドバーから「マップイベント」をクリックします
2. 編集したいイベントの「編集をする」ボタンをクリックします
3. イベント情報、マップ情報などを編集できます

#### イベント情報の詳細設定

イベント編集ページでは、以下の情報を設定できます：

-   名前：イベントの正式名称
-   見出し：マークダウン記法で書かれたイベントの説明文
-   公開・非公開：イベントをユーザーに公開するかどうか
-   リンク：関連ウェブサイトの URL
-   見出し画像 URL：イベントのメイン画像
-   マップ画像：イベントの地図画像
-   開始日時・終了日時：イベントの開催期間
-   イベントの場所：位置情報（緯度・経度）を含む場所情報
-   スタンプラリー機能：有効/無効の切り替え

### 場所と階層の管理

マップイベント内の場所（建物など）と階層（各フロア）を管理します。

#### 場所の追加

1. マップイベントの編集ページで「新しい場所を追加」ボタンをクリックします
2. 必要事項を入力します：
    - ID：場所を識別する一意の ID（半角英数字のみ）
    - 名前：場所の名称
    - X 座標/Y 座標：地図上での位置（0〜100 の範囲、単位は%）
    - 画像 URL：場所を表す画像の URL
3. 「追加」ボタンをクリックして作成を完了します

#### 階層の追加と編集

1. 場所の詳細ページで「新しい階層の追加」ボタンをクリックします
2. 必要事項を入力します：
    - ID：階層を識別する ID（半角英数字のみ）
    - 名前：階層の名称（例：1 階、2 階など）
    - 画像 URL：階層の地図画像の URL
    - 順番：表示順序（数字が小さいほど上に表示）
3. 階層内の催し物（ブースなど）を追加・編集できます

#### 階層内の催し物（ブース）の管理

1. 階層ページで「新しい催し物を追加」ボタンをクリックします
2. 必要事項を入力します：
    - 名前：催し物の名称
    - 見出し・説明：催し物の説明文
    - 画像 URL：催し物の画像
    - 開始・終了時刻：催し物の実施時間
    - 場所：催し物が行われる具体的な場所（教室名など）
    - 座標：階層地図上での位置（X・Y 座標）
    - 順番：表示順序

### 画像のアップロードと圧縮

TANE Core では、効率的なマップ表示のために画像のアップロードと圧縮機能が提供されています。この機能を使うことで、大きなサイズの画像を適切に圧縮してからサーバーにアップロードできます。

#### 画像アップロード機能の基本

1. サイドバーから「画像アップロード」をクリックします
2. 「ファイルをアップロード」セクションで以下のいずれかの方法で画像を選択します：
    - ドラッグ＆ドロップ：画像ファイルを点線で囲まれたエリアにドラッグします
    - クリックして選択：点線エリアをクリックしてファイル選択ダイアログを開きます
3. 選択された画像は自動的にアップロードが開始され、進捗状況が表示されます
4. アップロード完了後、画像 URL が生成され、この URL をコピーしてマップイベントや場所の設定で利用できます

※アップロードした画像は「画像一覧」ページで確認できます。

#### アップロードの制限事項

TANE Core の画像アップロードには以下の制限があります：

-   **対応ファイル形式**: png、jpg、jpeg、webp、svg のみ
-   **最大アップロード数**: 一度に最大 10 枚まで
-   **推奨サイズ**: 800px 以下の縦横サイズ（大きすぎる画像は表示速度に影響します）
-   **ユーザー権限**: 編集者（EDITOR）または管理者（ADMIN）権限を持ち、`@toko.ed.jp`で終わるメールアドレスを使用しているユーザーのみアップロード可能

#### 画像の圧縮方法

画像が大きすぎる場合は、アップロード前に圧縮できます：

1. 「ファイルを圧縮」セクションをクリックします
2. ドラッグ＆ドロップまたはクリックして圧縮したい画像を選択します
3. 画像は自動的に圧縮され、圧縮前後のサイズが表示されます
4. 圧縮後の画像に対して以下の操作ができます：
    - 「アップロード」：圧縮した画像を直接サーバーにアップロードする
    - 「ダウンロード」：圧縮した画像をローカルにダウンロードする

圧縮処理はブラウザ上で行われるため、サーバーに負荷をかけずに効率的に画像サイズを小さくできます。

#### 推奨される画像設定

TANE Map での表示に適した画像設定は以下の通りです：

-   **場所と行事の画像**: 16:9 の比率で表示されます
-   **催し物の画像**: 1:1（正方形）の比率で表示され、120px×120px が最適です
-   **マップの画像**: 1:1 の比率で表示され、SVG ファイル形式が推奨されます

#### 画像圧縮の仕組み

TANE Core では「browser-image-compression」という JavaScript ライブラリを使用して画像を圧縮しています。このライブラリは以下の特徴を持っています：

-   JPEG、PNG、WebP、BMP などの画像形式に対応
-   解像度やファイルサイズを調整して圧縮
-   Web Worker（マルチスレッド）を使用した効率的な処理
-   最大ファイルサイズと最大幅/高さを指定可能

圧縮オプションとして、以下のパラメータが設定されています：

-   `maxSizeMB: 0.08`（約 80KB）：圧縮後の最大ファイルサイズ
-   `maxWidthOrHeight: 1920`：最大の幅または高さ（ピクセル）
-   `useWebWorker: true`：バックグラウンドでの処理を有効化

#### トラブルシューティング

画像アップロードに問題がある場合は、以下を確認してください：

1. **アップロード権限**: 編集者（EDITOR）または管理者（ADMIN）権限があるか、正しいメールアドレスを使用しているか確認します
2. **ファイル形式**: サポートされているファイル形式（png、jpg、jpeg、webp、svg）を使用しているか確認します
3. **ファイルサイズ**: 画像が大きすぎる場合は、圧縮セクションを使用して小さくします
4. **ブラウザ互換性**: Google Chrome、Microsoft Edge、Safari の最新版を使用してください

大きすぎる画像をそのままアップロードすると、表示速度が遅くなったり、閲覧者のデータ通信量が増えたりする可能性があります。適切なサイズに圧縮することをお勧めします。

圧縮してもファイルサイズが大きい場合は、外部の画像編集ツール（例：[Squoosh](https://squoosh.app/)）を使用して、より小さいサイズに圧縮することも検討してください。

### スタンプラリー機能

イベント内でスタンプラリーを実施するための機能です。

#### スタンプラリーの有効化

1. マップイベントの編集ページで「スタンプラリー機能」の設定を「可能」に変更します

#### スタンプラリーの作成・編集

1. マップイベントの編集ページで「スタンプラリーの編集」を選択します
2. 「スタンプラリーの追加」ボタンをクリックします
3. 必要事項を入力します：
    - 名前：スタンプの名称
    - 画像 URL：スタンプの画像の URL
    - ヒント：スタンプを見つけるためのヒント
    - 表示順番：スタンプの表示順序
4. QR コードの生成・印刷もこのページから行えます

#### スタンプラリーの QR コード管理

1. スタンプラリー管理ページで「QR コードをダウンロード」を選択します
2. 各スタンプの QR コードが表示されます
3. 「QR をチェック」機能で QR コードの動作を確認できます
4. QR コードを印刷して実際のイベント会場に設置します

### お知らせの管理

TANE Map アプリに表示されるお知らせを管理します。

1. サイドバーから「リアルタイム連絡」をクリックします
2. 「お知らせの投稿」ボタンをクリックします
3. タイトル、種類、内容を入力して投稿します

お知らせは日付ごとに整理され、最新のものが上に表示されます。作成者の情報も含まれます。

## データベースと編集について

TANE Core は、Firebase というデータベースサービスを使用しています。編集したデータはリアルタイムで保存され、TANE Map アプリに反映されます。

### 編集時の注意点

-   **公開後の編集制限**：イベントを「公開」に設定すると、基本的に編集ができなくなります。これは、ユーザーのキャッシュを考慮した設計になっています。
-   **一度作成したデータの削除**：マップイベントや場所などの主要なデータは、一度作成すると削除できない仕様になっています。作成前によく確認してください。
-   **リアルタイム更新**：編集内容は他の編集者にもリアルタイムで表示されます。複数人での同時編集時は注意が必要です。

### マークダウン記法

イベントの見出しや説明文では、マークダウン記法が使えます。書式設定の詳細は「マークダウンガイド」ページを参照してください。

主なマークダウン記法：

-   見出し：`# 大見出し`、`## 中見出し`など
-   太字：`**太字**`
-   斜体：`*斜体*`
-   リスト：`- 項目1`、`1. 項目1`など
-   リンク：`[リンクテキスト](URL)`
-   画像：`![代替テキスト](画像URL)`

## 注意事項

1. **ブラウザの互換性**：Google Chrome、Microsoft Edge、Safari 最新版での利用を推奨します。
2. **画像サイズ**：アップロードする画像は適切なサイズに圧縮してください。大きすぎる画像はアプリの表示速度に影響します。
3. **公開時の確認**：イベントを公開する前に、すべての情報が正しく設定されているか確認してください。
4. **アクセス制限**：TANE Core へのアクセス URL を関係者以外に共有しないでください。
5. **メールアドレス**：基本的に`@toko.ed.jp`メールアドレスをお持ちの方しかログインできません。
6. **バックアップ**：重要なデータは別途バックアップを取っておくことをお勧めします。

## トラブルシューティング

### 画面が正しく表示されない場合

1. ブラウザのキャッシュをクリアしてみてください
2. 別のブラウザで試してみてください
3. デバイスを再起動してみてください

### データが保存されない場合

1. インターネット接続を確認してください
2. 編集権限があるか確認してください
3. 公開状態のイベントではないか確認してください

### ログインできない場合

1. 使用しているメールアドレスが`@toko.ed.jp`で終わっているか確認してください
2. Google アカウントでログインしているか確認してください
3. インターネット接続を確認してください

## よくある質問

**Q: 権限を変更するにはどうすればいいですか？**  
A: 権限の変更は管理者（ADMIN）のみが行えます。管理者に連絡して変更を依頼してください。

**Q: 間違えてイベントを作成してしまいました。削除できますか？**  
A: 一度作成したイベントは削除できません。管理者に連絡して対応を相談してください。

**Q: 画像をアップロードしようとするとエラーになります**  
A: 画像アップロードには編集者（EDITOR）権限と`@toko.ed.jp`メールアドレスが必要です。また、画像サイズが大きすぎないか確認してください。

**Q: マップイベントを公開した後も編集できますか？**  
A: イベントを公開状態にすると、基本的に編集はできなくなります。これはユーザーのキャッシュを考慮した仕様です。

**Q: TANE Map での表示を確認するには？**  
A: `https://map.toko-tane.net/` にアクセスすることで、TANE Map での表示を確認できます。

**Q: 複数のイベントを同時に管理できますか？**  
A: はい、複数のイベント（例：オープンスクールと文化祭）を独立して管理できます。

**Q: スマートフォンからも編集できますか？**  
A: 基本的にはパソコンでの操作を推奨していますが、スマートフォンからも基本的な編集は可能です。ただし、一部の機能は使いにくい場合があります。
