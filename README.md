## 開発環境構築（1 回のみ）

1. Nodejs をインストールします。

    URL: https://nodejs.org/en

2. 依存ライブラリをインストールします。

    ```
    npm install
    ```

3. 環境変数の設定

    [Firebase のアプリの設定](https://console.firebase.google.com/project/tane-project/settings/general/web:YjM2ZDQwY2QtZTIwNy00MTliLTg4YWEtYTIzYjkxYjViN2Fm)から firebaseConfig 変数の中から env ファイルにコピーします。

```
VITE_API_KEY=<->
VITE_AUTH_DOMAIN=<->
VITE_PROJECT_ID=<->
VITE_STORAGE_BUCKET=<->
VITE_MESSAGING_SENDER_ID=<->
VITE_APP_ID=<->
VITE_MEASUREMENT_ID=<->
VITE_RECAPTCHA_SITE_KEY=<->
```
